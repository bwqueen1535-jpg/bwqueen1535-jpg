# B站视频总结

把一个B站视频总结成结构化内容。流程：运行抓取脚本拿字幕 → 由你直接总结。不需要任何外部 AI API。

## 第一步：抓取字幕

对用户给的链接/BV号/av号运行插件自带脚本（脚本位于插件根目录 `scripts/bili-subtitles.mjs`，即技能基目录向上两级；路径可用正斜杠）：

```bash
node "<技能基目录>/../../scripts/bili-subtitles.mjs" "<视频链接或BV号>"
```

- 分P视频加 `--p 页码`；链接里带 `?p=N` 时脚本会自动识别。
- 正常输出：标题、UP主、时长、分P信息、简介、按段合并的字幕（段首为起始时间）。

退出码含义：
- `0`：拿到字幕（脚本已做过时长校验），进入第二步。
- `2`：视频没有字幕。改用脚本输出的标题和简介做总结，并明确告诉用户"该视频没有字幕，以下基于简介总结"。
- `3`：字幕内容校验失败——B站风控导致接口返回错乱。告诉用户等几分钟后重试，不要直接总结错乱内容。
- `1`：请求或解析失败。把脚本输出的错误转述给用户；最多重试一次。

## 第二步：生成总结

对脚本输出直接总结，格式如下：

```markdown
## 《标题》
<一句话概括整个视频>

## 要点
- [m:ss] <要点，保留时间戳方便用户跳转，5~8 条>

## 适合谁看
<一行，可选>
```

要求：修正字幕里的错别字；要点按视频顺序排列；默认中文输出（用户另有语言要求除外）；字幕超过 60 段的长视频，优先挑讲干货的段落。

## SESSDATA 配置（拿不到字幕时指导用户）

未设置环境变量 `BILIBILI_SESSDATA` 时，B站常不返回字幕轨道。指导用户：

1. 浏览器登录 bilibili.com，按 F12 → 应用/存储 → Cookies → 复制 `SESSDATA` 的值；
2. Windows 执行 `setx BILIBILI_SESSDATA "复制的值"`，然后重启 ZCode 生效。

不要把 SESSDATA 的值写进任何文件或对话记录。
